# Technical Specs (as-built, SAU khi code)

Xong một feature lớn → 1 file `<feature>.md` để người đọc sau này hiểu được:

- **What was built**: tóm tắt 2-3 câu.
- **End-to-end flow**: input → ... → output, kèm file + hàm chính.
- **Files changed**: path — vai trò.
- **Decisions made during implementation**: những thứ phát sinh khi code, khác với spec.
- **How to verify**: chạy lệnh gì để xác nhận (kèm kết quả thật đã chạy).
- **Things to watch**: tech debt, TODO, giới hạn đã biết.

Các as-built hiện có:

- `pipeline-restructure.md`
- `realtime-segmentation.md`
- `check-tool.md`
- `video-ingest-readiness.md`
